# Changelog

All notable changes are documented here.

## 1.0.1 - 2026-09-02

- Renamed the app from Leftbar to Refill.
- Added automatic migration for existing account metadata and cached quota values.

## 1.0.0 - 2026-09-02

- Added a native macOS menu-bar view for Claude, Codex, and Grok quota.
- Named the app Leftbar and added generated repository artwork from the native UI.
- Added Claude, Codex, and Grok logos to the provider section headers.
- Added multi-account discovery from T3 and local provider homes.
- Added Claude model-scoped limits, including a separate Fable row and reset time.
- Added stale-value caching, local JSON export, launch at login, and five-minute refreshes.
- Added account rename, removal, isolated sign-in, and reauthentication flows.
- Added native and universal builds, macOS 13 deployment verification, and release packaging.
