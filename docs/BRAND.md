# Refill brand

## Name

Use **Refill** as one word with a capital `R`. The name refers to quota windows filling again when their reset time arrives.

Do not write `ReFill`, `Re-fill`, or `Quota` as the product name. Quota remains the generic name for the limits it reads.

## Copy

- Headline: `Know what's left. Know when it refills.`
- Description: `Refill shows what's left and when it resets across Claude, Codex, and Grok accounts from the Mac menu bar.`
- Repository description: `Track Claude, Codex, and Grok quota from the Mac menu bar.`

## Mark

The mark is an orange rounded square with three dark, left-aligned bars. The bars refer to the provider limits in the popover. Use `Media/app-icon.png` for listings and the generated `.icns` inside the app.
